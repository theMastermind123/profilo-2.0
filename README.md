## Features

- Responsive, terminal-style portfolio UI
- Kali Linux color theme and visuals
- Autocomplete (TAB / Ctrl+i)
- Command history navigation (Up / Down)
- Built-in commands: about, help, projects, resume, socials, email, education, etc.
- Keyboard-first experience (type commands, open windows, toggle fullscreen)

## 🎨 Configuration — make it yours

Everything personal now lives in **one file**: [`src/config/portfolio.ts`](src/config/portfolio.ts).
Edit it and the terminal, desktop shortcuts, browser window, resume window, SEO
meta and structured data all update automatically — you don't need to touch the
components or `index.html` at all.

| Config key   | What it controls                                                          |
| ------------ | ------------------------------------------------------------------------- |
| `identity`   | Name, role, location, avatar and email                                    |
| `about`      | The `about` command text                                                  |
| `education`  | The `education` command list                                              |
| `projects`   | The `projects` command + `projects go <id>` redirects                     |
| `socials`    | The `socials` command + `socials go <id>` redirects                       |
| `resume`     | `resume` command URL + the PDF shown in the resume window                 |
| `terminal`   | Prompt (`user@host`), boot commands, ASCII banner, `pwd`/`whoami`, eggs   |
| `commands`   | The list shown by `help`                                                  |
| `desktop`    | Desktop shortcut icons (open a window or an external link)                |
| `browser`    | Welcome window hero, quick links and highlight cards                      |
| `seo`        | `<title>`, meta, Open Graph / Twitter, fonts & JSON-LD (injected at build) |

Then swap the static assets in `public/`:

- `public/*.jpg` — your photo → point `identity.avatar` (and `seo.image`) at it
- `public/*.pdf` — your resume → point `resume.pdfPath` (and the browser Resume quick-link) at it
- `public/favicon.png` and `public/og.jpg`

### Project structure

```
src/
├── config/          # 👈 portfolio.ts — the only file you normally edit
├── app/             # App.tsx + main.tsx entry points
├── features/
│   ├── terminal/    # Terminal, commands and their styled components
│   ├── desktop/     # Desktop shortcuts + fullscreen toggle
│   └── windows/     # Browser / Resume / Terminal windows
├── hooks/           # useTheme
├── styles/          # GlobalStyle + themes
└── utils/           # helpers (funcs, storage)
```

A `@/*` path alias maps to `src/*` (configured in `tsconfig.json` and
`vite.config.ts`). The document `<head>` is generated by the `portfolio-seo`
Vite plugin from the `seo` section of the config.

## Run locally

Clone the project and install dependencies:

```bash
git clone https://github.com/abdannassermbarki/Kali-Linux-Hacker-Portfolio.git
cd Kali-Linux-Hacker-Portfolio
git remote remove origin
pnpm install
pnpm dev
```

> The repo uses pnpm in the workspace; `npm install` also works but `pnpm` is recommended for speed and deterministic installs.
